# Personal Assistant CLI (`project-platipus`)

Консольний асистент на Python для роботи з контактами та нотатками з локальним збереженням у JSON, валідацією вхідних даних і захистом від втрати даних при помилках читання або запису.

## Можливості застосунку

- **Контакти та дні народження**: створення, перегляд, редагування, видалення контактів, пошук, робота з телефонами, email і датами народження, а також перегляд найближчих днів народження.
- **Нотатки, теги та сортування**: створення, перегляд, редагування, видалення нотаток, пошук за текстом, додавання тегів через кому з нормалізацією та захистом від дублікатів, пошук за тегом та сортування за релевантністю вибраним тегам.
- **Валідація та підказки**: перевірка коректності введених даних, інтерактивні/аргументні сценарії та підказки щодо формату/помилок.
- **Безпечне сховище**: окрема обробка помилок файлу/JSON, схеми та записів; атомарний запис через тимчасовий файл і `os.replace()`; відстеження незбережених змін (`dirty`) і повторне збереження (`retry-save`).

## Встановлення та запуск

### Вимоги
- **Python 3.11+** (перевірено на Python 3.15).

### 1. Клонування репозиторію
```bash
git clone [https://github.com/Tetiana-cyber/project-platipus.git](https://github.com/Tetiana-cyber/project-platipus.git)
cd project-platipus
```

### 2. Віртуальне середовище (`venv`)

**macOS / Linux:**
```bash
python3 -m venv .venv
source .venv/bin/activate
```

**Windows (PowerShell):**
```powershell
python3 -m venv .venv
.venv\Scripts\Activate.ps1
```

**Windows (Command Prompt / `cmd.exe`):**
```cmd
python3 -m venv .venv
.venv\Scripts\activate.bat
```

### 3. Встановлення залежностей і запуск
```bash
python3 -m pip install --upgrade pip
python3 -m pip install pytest ruff
```
*(Якщо у репозиторії з'явиться `pyproject.toml` або `setup.py`, додатково можна виконати `pip install -e .`.)*

Запуск застосунку (після мерджу основного пакета та CLI-модулів у `main`):
```bash
PYTHONPATH=. python3 -m assistant
```

## Команди та приклади використання

- **Контакти та дні народження**: CRUD-операції з контактами, пошук, валідація полів та перегляд найближчих днів народження.
- **Нотатки та пошук за текстом**:
  ```text
  find-note звіт
  ```
- **Теги (один або кілька через кому, нормалізація та Unicode)**:
  ```text
  add-tag 1 терміново, work, existing
  ```
- **Пошук за точним нормалізованим тегом**:
  ```text
  find-by-tag work
  ```
- **Сортування нотаток за релевантністю вибраним тегам**:
  ```text
  sort-notes work, urgent
  ```

## Правила введення даних

- **Телефон (`phone`)**: коректний номер телефону згідно з правилами валідатора контактів.
- **Email (`email`)**: коректна адреса електронної пошти формату `local@domain.tld`.
- **Дата (`date`)**: дата у стандартизованому форматі, прийнятому у валідаторі/моделі проєкту.

## Збереження даних, помилки та відновлення

- **Місце збереження**: локальний JSON-файл сховища (шлях задається конфігурацією/менеджером сховища).
- **Помилки читання, схеми та записів**: помилки завантаження/JSON, версії чи структури схеми та окремих записів обробляються окремо, не затирають наявний файл і не підміняють стан порожньою книгою.
- **Помилки збереження та `retry-save`**: при помилці запису/заміни попередній файл зберігається, успішне повідомлення не виводиться, стан незбережених змін (`dirty`) залишається активним; повтор збереження (`retry-save`) повторює запис обох книг без повторної мутації та очищує `dirty` при успіху. При виході (`exit`, `EOF`, `Ctrl+C`) за наявності незбережених змін виводиться попередження та запит підтвердження (якщо ввід доступний).
